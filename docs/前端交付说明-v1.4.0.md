### 2.1 接口变更

| 接口 | 变更 |
| --- | --- |
| `POST /queue/scan_checkin` | 核销成功后消费票号，并记录使用者（2 小时过期） |
| `POST /queue/scan_checkout` | **新增**，请求 `{ "stall_id": "F01" }`，离场并释放隔间 |
| `GET /queue/my_ticket` | 核销后由 `calling` 变为 `no_ticket` |
| `WS /ws/stalls` | 建连即发送 `{"type":"stalls_update","data":[...]}`；HTTP 写操作后同样推送 |
| `POST /queue` | 使用中的用户再次取号返回 400 |

## 6. 已知问题

| 类型 | 内容 |
| --- | --- |
| 可靠性 | `safeFetch` 在网络错误/5xx 时回退 Mock，核销/取消/报修可能“前端成功、后端未记录” |
| 安全 | JWT 无 `exp`，签发后不过期；未配置 `JWT_SECRET` 时重启会使全部 Token 失效 |
| 安全 | `/queue/cancel` 未校验票号归属，知道他人 `ticket_id` 可将其移出队列 |
| 实时性 | 仿真器默认不自动启动，前端也未调用 `/sim/start`；无仿真时只有写操作会触发推送 |
| 数据 | 隔间 `assign_time` 在释放后仍保留，不影响展示，属残留字段 |
| 离线 | 离线账号仅存当前浏览器；后端恢复后旧离线会话首次请求会因 Token 无效退出 |

## 8. 启动方法

```powershell
# 1) Redis（6379）
netstat -ano | findstr :6379

# 2) 后端（项目根目录）
.\.venv\Scripts\python.exe -m uvicorn main:app --port 8000

# 3) 前端
cd frontend
npm install
npm run dev
```

- 后端文档：`http://127.0.0.1:8000/docs`
- 前端地址：`http://localhost:5173`

前端可选环境变量（`frontend/.env.local`）：

```bash
VITE_BATHHOUSE_ID=1
VITE_BATHHOUSE_NAME=1 号楼浴室
VITE_BATHHOUSE_AREA=宿舍 1 栋
# 前后端分域部署时填写，未配置则使用当前页面同域
VITE_WS_URL=ws://127.0.0.1:8000
```
