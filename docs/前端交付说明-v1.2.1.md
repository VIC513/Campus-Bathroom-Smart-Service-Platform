### 2.2 后端（联调阻塞项）

## 7. 启动方法

```powershell
# 1) Redis（6379）
netstat -ano | findstr :6379

# 2) 后端（项目根目录）
.\.venv\Scripts\python.exe -m uvicorn main:app --port 8000

# 3) 前端
cd frontend
npm install
npm run dev
```

- 后端文档：`http://127.0.0.1:8000/docs`
- 前端地址：`http://localhost:5173`
